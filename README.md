# Project Switcher

macOS 菜单栏小工具。在任意应用里按 `⌥S`，弹出屏幕中央的搜索浮层，用来切换已经打开的 Cursor 项目和工作区，也可以从你配置的目录里找出还没打开的项目并打开。

它和编辑器里的 Project Manager 各管一段：扩展负责标签、置顶和更深的项目库；这个工具负责你人在别的应用里时，快速回到或打开一个 Cursor 项目。

## 能做什么

- 全局热键 `⌥S` 唤起或收起浮层
- 列出当前已打开的 Cursor 项目和工作区，输入名字或路径即可过滤
- 回车或点击：已打开的切到对应窗口，未打开的按当前布局新开
- 已打开的条目右侧可以关掉该项目窗口，浮层保持打开
- 菜单栏可配置项目目录、工作区目录，以及打开时用 Editor 还是 Agent
- 菜单栏常驻，可勾选登录时启动

## 第一次使用

1. 把 **Project Switcher** 放进「应用程序」，并从那里启动。菜单栏会出现窗口图标，Dock 里没有图标。
2. 打开 **系统设置 → 隐私与安全性 → 辅助功能**，勾选 **Project Switcher**。路径应是 `/Applications/Project Switcher.app`。
3. 系统若再询问是否允许控制 **System Events**，选择允许。列出和关闭窗口时会用到这项授权。
4. 回到任意应用，按 `⌥S`。

请只保留「应用程序」里这一份。重新安装后签名会变，需要重新勾选辅助功能，然后完全退出再打开。未授权时，窗口列表是空的；登录时启动也要求 App 装在「应用程序」里。

菜单栏里的「打开辅助功能设置…」可以直接跳到授权页面。

## 日常操作

1. 按 `⌥S`，或点菜单栏图标里的「显示切换器」。
2. 不输入时，只显示已经打开的项目和工作区。
3. 输入后，还会带上扫描目录里尚未打开的项目和工作区，已打开的不会重复出现。
4. 用方向键选择，回车或点击打开。`Esc`、再按一次 `⌥S`，或点击浮层外面，都会收起。

已打开的行右侧有关闭按钮。关闭由对应的 Cursor 窗口自己完成，一般不用先切过去。第一次使用关闭前，请先完全退出并重新打开一次 Cursor，让关闭助手生效。关不掉时，浮层会提示原因；工作区关闭还依赖辅助功能，可按提示重新授权后再试。

## 列表说明

- 普通项目显示文件夹图标；`.code-workspace` 带「工作区」标记；还没打开的带「未打开」标记
- 同一个项目的多扇窗口合并成一条
- 只作为某个工作区成员、自己没有独立窗口的文件夹不会单独占一行
- 在这个切换器里点开过的项目，下次会排在前面
- 开发者工具等无关窗口不会出现

打开时的布局在菜单栏「打开窗口布局」里选，默认是 **Editor（经典窗口）**。改成 **Agent** 后，之后新开和切换都走 Agent 布局。

## 扫描路径

菜单栏选择「配置扫描路径和工作区…」。这些路径默认不进列表，只有搜索时才出现，点一下即可打开。

**项目目录**只看一层子文件夹。这一层里如果有 `.code-workspace`，也会当成工作区。可以粘贴路径（一行一个），或点「选择…」一次加多个文件夹。

**工作区目录**只看一层 `.code-workspace`，里面的子文件夹不会被当成项目。

## 菜单栏

- 显示切换器
- 打开辅助功能设置
- 登录时启动
- 打开窗口布局：Editor 或 Agent
- 配置扫描路径和工作区
- 退出

## 目前不做

Project Manager 里的标签、置顶、隐藏和打开次数，以及 Windows / Linux，都不在这个工具里。
